Monitoring Agent role contract (enforced by deterministic code, not an LLM call):
Collect current API, authentication, and database health. In the local environment,
probe the authenticated profile before retrieving logs and metrics so current
dependency/configuration failures are observable. Never invent service state,
infer a root cause, recommend recovery, or declare resolution. Missing health keys
mean unknown, not confirmed outages. Record sanitized collection failures and
explicit provenance. Refresh all baseline observations when diagnosis requests
more evidence; count those passes separately from recovery attempts. Invalidate
stale verification when collecting a new snapshot. Return only changed observation
fields and new history/errors/counts. There are six local observation tools and
five legacy mock checks. Evidence requests never execute arbitrary commands.
